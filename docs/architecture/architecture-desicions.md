# Архитектурные решения

## apps/frontend

1. Критерий размещения компонента

> Компонент (секция) кладётся в `pages/page-name/*`, если он используется **только** на этой странице. Как только он нужен в двух местах - переезжает в `widgets/*` или `features/*`.

2. Правило контекста

> Контекст, созданнный внутри `pages/page-name/*`, является приватной деталью реализации. Он не реэкспортируется из `index.ts` страницы. Использование контекста одной страницы в другой - запрещено.

3. Сигналы рефакторинга

> - Компонент используется на 2+ страницах -> `widgets/*`
> - Контекст нужен 2+ страницам -> `features/*` или `shared/contexts/*`
> - Секция обросла собственной бизнес-логикой -> `features/*`
