## 📋 Описание проекта

### Идея

Записаться к барберу в 2024 году всё ещё неудобно: кто-то принимает только через Instagram, кто-то только по телефону, расписание непонятно, а напоминание о визите никто не присылает. **BarberHub** решает эту проблему — это платформа, где пользователь может найти барбершоп, выбрать мастера, посмотреть его работы и записаться онлайн в пару кликов.

### Целевая аудитория

- **Клиенты** — люди, которые хотят удобно записаться к барберу
- **Владельцы барбершопов / мастера** — хотят управлять расписанием и получать клиентов без звонков

---

### 🖥 Ключевые экраны и функциональность

#### Для клиента (роль: `user`)

| Экран                   | Что можно делать                                                                                                       |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **Главная**             | Поиск барбершопов по городу/метро, фильтрация по рейтингу, цене, расстоянию. Карта с метками барбершопов (Yandex Maps) |
| **Карточка барбершопа** | Информация о заведении, список мастеров, фото, рейтинг и отзывы                                                        |
| **Карточка мастера**    | Портфолио работ, список услуг с ценами и длительностью, доступные слоты                                                |
| **Запись**              | Выбор услуги → выбор даты → выбор свободного слота → подтверждение                                                     |
| **Личный кабинет**      | История записей (прошлые и будущие), редактирование профиля, смена пароля                                              |
| **Мои записи**          | Список предстоящих записей со статусом, возможность отменить запись                                                    |

#### Для мастера / владельца (роль: `master`)

| Экран                      | Что можно делать                                                      |
| -------------------------- | --------------------------------------------------------------------- |
| **Дашборд**                | Сводка: записи на сегодня, загруженность недели                       |
| **Управление расписанием** | Настройка рабочих часов, блокировка дней (отпуск, выходной)           |
| **Управление услугами**    | CRUD услуг: название, цена, длительность                              |
| **Записи**                 | Список всех записей, смена статуса (подтверждён / выполнен / отменён) |
| **Профиль мастера**        | Редактирование портфолио, описания, контактов                         |

#### Для администратора (роль: `admin`)

| Экран            | Что можно делать                                           |
| ---------------- | ---------------------------------------------------------- |
| **Admin-панель** | Управление пользователями, барбершопами, модерация отзывов |

---

### ✨ Уникальные фичи

1. **Умный поиск** — фильтрация по цене, расстоянию, рейтингу, свободным слотам на конкретную дату
2. **Статусная модель записи** — `pending → confirmed → completed / cancelled`
3. **Email-уведомления** — подтверждение записи, напоминание за 2 часа, уведомление при отмене
4. **Карта барбершопов** — интеграция с Yandex Maps, геолокация пользователя
5. **Система отзывов** — оценка и комментарий только после завершённой записи

## 🗂 Сущности системы

| -------------- | ---------------------------------------------------------- |

| `TimeSlot`     | id, master_id, date, start_time, is_booked                 |
| `Appointment`  | id, user_id, master_id, service_id, slot_id, status, notes |
| `Review`       | id, user_id, master_id, appointment_id, rating, comment    |
| `Notification` | id, user_id, type, message, is_read, sent_at               |

## 👤 User Stories

```
Как клиент, я хочу найти барбершоп рядом с домой по карте,
  чтобы не тратить время на дорогу.

Как клиент, я хочу видеть свободные слоты мастера на нужную дату,
  чтобы выбрать удобное время без звонков.

Как клиент, я хочу получать email-напоминание о записи,
  чтобы не забыть про визит.

Как мастер, я хочу управлять своим расписанием и блокировать выходные,
  чтобы клиенты не записывались в нерабочее время.

Как мастер, я хочу видеть все предстоящие записи в дашборде,
  чтобы планировать свой день.

Как admin, я хочу модерировать отзывы и управлять барбершопами,
  чтобы поддерживать качество платформы.
```

## 🚀 Как запустить локально

```bash
# 1. Клонировать репозиторий
git clone https://github.com/username/barberhub.git
cd barberhub

# 2. Создать .env файлы (примеры ниже)
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env

# 3. Запустить через Docker Compose
docker compose up --build
```

Приложение будет доступно:

- Frontend: http://localhost:5173
- Backend API: http://localhost:3000
- Swagger: http://localhost:3000/api-docs

### Переменные окружения (backend)

```env
DATABASE_URL=postgresql://user:password@localhost:5432/barberhub
JWT_SECRET=your_secret_key
JWT_REFRESH_SECRET=your_refresh_secret
MAIL_HOST=smtp.gmail.com
MAIL_USER=your@gmail.com
MAIL_PASS=your_app_password
YANDEX_MAPS_KEY=your_key
```
